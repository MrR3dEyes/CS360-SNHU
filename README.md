# CS360-SNHU
CS-360-MobileArchitect&amp;Programming

The Weight tracker app creates was made for simple and private weight monitoring by allowing users to log daily weight, view progress overtime, as well as set goals. The core requirements were CRUD operations, user authentication and SMS permissions as well as offline data storage and proper Android Guidelines. The application had four main screens that supported user needs a login screen for per user secure access, a home screen for weight entry, progress screen for data review and management, finally the profile section to adjust the users profile, login, sms and more. The UI is minimalistic and focuses on speed, clarity, and minimal effort for entry and data mangement. The system was built layer by later throughout an iterative approach and prioritized a functional application and proper input validation. The clear naming conventions, documentation and proper coding conventions all helped with proper layout of the application. Every screen had its own java file for proper management and UI file for proper layout. The two conjoined makes it easier for mangement of a specific section of the application. Finally testing for said system was very fun, being able to login with a new user or old user or improper user to ensure system functionality was great, not to mention ensuring input and data entries were valid as well. The issues found and relibality made it easier to then determine said issues. I had problems with the table and no entries at first, then adding or removing entires and data staying the same. Testing in a sense was somewhat brute force but revealed the issues that needed to be resolved! I definitely had to figure out proper XML layouts as some caused issues, some UI elements and layout was a bit redundant or problematic, fixing the UI and ensuring that app functionality was possible such as moving throughout the application and proper menus was hard at first but eventually solved this was definitely the hardest part of the process and still is. Ive had issues with ensuring proper inputs, as well as UI functionality but after ensuring proper layouts are created its become easier. The database would be my strongest achievement from said system as Ive created a database with proper SQLite architecture as well as CRUD operation and great error handling. I had issues with input, data management, and even adding or deleting data, but eventually I understood the integration of data and UI and was able to ensure proper functionality.
